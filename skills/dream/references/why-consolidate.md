# なぜ consolidation が必要か

エージェントは毎セッションで記憶へ追記する。
追記は局所的・増分的なので、20〜30 セッションを超えると次の症状が出る。

- 同じ知見が複数ファイルに書かれている (重複)
- 相対日付 ("先週"・"昨日") が時間経過で意味を失う
- 削除済みファイル・改名されたシンボル・revert された PR への参照が残る (陳腐化)
- ハーネスのネイティブ機能と重複した自作ユーティリティの言及が残る (機能被り)
- 上位レイヤ (グローバル CLAUDE.md) のルールを下位 (auto memory) で再掲している (階層汚染)

これらの症状が出ていれば、記憶は「思い出す助け」から「混乱させるノイズ」へ転落している。
consolidation を実施する。
